# Plum CRM

Компактная CRM для небольшой B2B-команды. React + TypeScript + Vite, данные хранятся локально в браузере.
Языки интерфейса: украинский, русский, английский. Тёмная тема, валюта демо — USD.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc -b && vite build
npm test           # vitest: модель, метрики, хранилище, сценарии интерфейса, axe
```

UI-кит открывается по адресу `/ui-kit` (в меню его нет).

## Возможности

- **Обзор:** показатели и аналитика (средний чек, срок закрытия, прогноз, конверсия) с выбором периода, графики по этапам, сумме и динамике (по дням / по месяцам), последние обновления.
- **Сделки:** доска с перетаскиванием между колонками (и выпадающим списком этапа для клавиатуры и телефона), поиск, фильтры по этапу и контакту, сортировка, создание, правка, удаление с отменой.
- **Контакты:** таблица с сортировкой по столбцам, поиск, правка, удаление с отменой, список сделок контакта.
- **Заметки:** рабочие заметки по дням, привязка к сделке и контакту, фильтры, пометка «Просрочено».
- **Кабинеты компаний:** блок компании сверху (фото, название, расчётный счёт, ИНН, IBAN со скрытием и копированием), переключение между компаниями, у каждой свои данные.
- **Резервная копия:** выгрузка и восстановление всех данных одним JSON-файлом (в окне «Компании и данные»).
- **Быстрый поиск:** `Ctrl+K` — по сделкам, контактам, заметкам и разделам.

## Данные

Хранятся в `localStorage` под ключом `plum-crm:v4` (язык — `plum-crm:lang`). Данные старого формата (`plum-crm:v3`) переносятся автоматически. Повреждённые записи отбрасываются, ошибки записи показываются баннером.

## Структура

```
src/
  components/   общие компоненты (кнопки, поля, панели, графики, уведомления, поиск)
  pages/        Обзор, Сделки, Контакты, Заметки, UI-кит
  lib/          типы, хранилище, стор, метрики, демоданные
  i18n/         словари uk / ru / en
  styles/       токены (tokens.css) и стили (app.css)
  test/         тесты интерфейса
assets/reference/   исходные макеты и логотип (не входят в сборку)
```

## Заглушки

Кнопки «Упаковать в XLS», «Выгрузить файлом» и «Отправить в Телеграм» на «Обзоре» пока показывают сообщение «Функция скоро появится».
